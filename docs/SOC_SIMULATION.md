# SOC Simulation Architecture & Safety Guide

## Overview

Phase 9 transforms the Enterprise SOC Laboratory into a **Simulation, Analyst Training & Operational Validation Platform**.  
All telemetry events generated by this engine carry `source_mode = "simulation"` and are never claimed to originate from real physical endpoints.

## Safety Contract

| Action | Behavior |
|---|---|
| Scan external hosts | ❌ NEVER performed |
| Send malicious traffic | ❌ NEVER performed |
| Modify real machines | ❌ NEVER performed |
| Disable real accounts | ❌ NEVER performed |
| Real firewall changes | ❌ NEVER performed |
| Simulate telemetry in isolation | ✅ Always enforced |
| Label events `source_mode = "simulation"` | ✅ Always enforced |

Physical Windows, Linux, Kali, Wazuh, Suricata, and Zeek integrations remain **NOT CONNECTED** unless explicitly configured by an administrator.

## Architecture

```
Analyst Request (UI / API)
        ↓
ScenarioEngine (src/simulation/engine.py)
        ↓
scenarios.py → generate_events() [source_mode = "simulation"]
        ↓
TelemetryPipeline.process_event()
  → Validation → Normalization → Deduplication
  → Storage → Detection → Correlation → Risk Score
        ↓
Alert / Incident / Case created (real workflow)
        ↓
Analyst Training Module (src/simulation/training.py)
        ↓
AnalystScoringEngine (src/simulation/scoring.py)
        ↓
Scorecard + Training Report
```

## Source Mode Labeling

Every generated event includes:
```json
{
  "source_mode": "simulation",
  "simulation": true,
  "environment": "lab"
}
```

Alerts triggered from simulated events inherit `source_mode = "simulation"` and are tagged with `["simulation"]`.

## Simulation Isolation

- Scenarios run in the standard SOC database (alerts, events, incidents)
- Each scenario run is recorded with a unique `run_id` in the `scenario_runs` table
- Replay creates a **new** `run_id` — historical data is immutable
- Execution concurrency locked: only one scenario can run at a time

## Known Limitations

- Physical endpoint telemetry is NOT connected at this stage
- All telemetry is produced synthetically from scenario step templates
- SOAR LIVE mode remains disabled (Phase 8 safety gate)
